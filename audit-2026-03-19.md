# jasonsteltman.com — Security & Code Quality Audit
**Date:** 2026-03-19
**Auditor:** Claude (vibe-security skill + manual review)
**Scope:** index.html, blog.html, art.html, cv.html, web.html

---

## CRITICAL

*No critical vulnerabilities found.* Static site with no backend, no user auth, no data storage. Minimal attack surface.

---

## HIGH

### H1. XSS via innerHTML in art.html
**File:** `art.html` lines 202-224
`renderArt()` uses template literals with project data interpolated into `innerHTML`. Data is currently hardcoded (self-XSS only), but if source ever changes to external input, this becomes exploitable. index.html and blog.html use `textContent`/`createElement` — art.html is the outlier.
**Fix:** Switch to `createElement`/`textContent` pattern.
**Status:** ✅ Fixed 2026-03-19

### H2. External Fonts Loaded from CDN Without SRI
**File:** `index.html` lines 19-21
Google Fonts and Fontshare loaded without `integrity` attributes. CDN compromise could inject malicious CSS.
**Fix:** Self-host `.woff2` files. Already in to-do list.
**Status:** 🔲 Deferred (self-hosting fonts is a separate task)

### H3. Email Address Exposed in Source
**File:** `index.html` lines 278, 717
`jason.steltman@gmail.com` hardcoded — easily scraped by bots.
**Fix:** JS-assemble the email string or route through Formspree.
**Status:** ✅ Fixed 2026-03-19

## MEDIUM

### M1. Contact Form Uses mailto: — No Server-Side Handling
`sendContactEmail()` opens mail client — broken on most mobile web browsers. Formspree already in CSP.
**Fix:** Wire to Formspree.
**Status:** ✅ Fixed 2026-03-19

### M2. "Download CV" Is a Dead Link
`href="#"` — scrolls to top on click.
**Fix:** Add real PDF or remove until one exists.
**Status:** ✅ Fixed 2026-03-19

### M3. No `rel="noopener noreferrer"` on External Links
All `target="_blank"` links across all files.
**Fix:** Add `rel="noopener noreferrer"` globally.
**Status:** ✅ Fixed 2026-03-19

### M4. CSP Missing on Subpages
Only `index.html` has a CSP meta tag. `blog.html`, `art.html`, `cv.html`, `web.html` have none.
**Fix:** Add same CSP to all pages.
**Status:** ✅ Fixed 2026-03-19

### M5. CSP Allows `unsafe-inline` for Scripts
Inline `<script>` blocks require this. Acceptable for static site but weakens protection.
**Fix:** Long-term: external JS + nonce CSP. Low priority for static personal site.
**Status:** 🔲 Deferred

### M6. Behance CDN Images Have No Fallback
If Behance rotates CDN paths, all art cards break silently.
**Fix:** Self-host cover images or add `onerror` fallback.
**Status:** ✅ Fixed 2026-03-19 (onerror fallback added)

### M7. `photoroll/` Directory Missing from Repo
Hero photo roll references 9 images that don't exist in repo.
**Fix:** Commit the `photoroll/` directory.
**Status:** 🔲 Needs user action (images need to be provided)

### M8. Duplicate Images in Root and `images/`
Every screenshot PNG exists twice — doubles repo size.
**Fix:** Consolidate to `images/`, update references, delete duplicates.
**Status:** 🔲 Deferred (low risk, cleanup task)
