EventLineup

A live event calendar for the GTA pulling from Ticketmaster, Eventbrite, Bandsintown, Songkick, and StubHub. Browse concerts, theatre, comedy, festivals, and sports across 28 venues in an 80km radius. Includes a discover mode, hot-date heatmap, and real-time sync.

GitHub Trending Repos

A clean dashboard that scrapes and displays daily, weekly, and monthly trending GitHub repositories. Browse in grid view or raw JSON, filter by language, and drill into individual repos for star counts, forks, contributor stats, and trending velocity — all in one place.

Ontario Markets

Discover farmers' markets across Ontario — fresh produce, local artisans, and community spirit. Browse 35 markets across 6 regions, filtered by date on an interactive calendar. Each listing shows hours, tags, indoor/outdoor status, and links directly to the market's website.
