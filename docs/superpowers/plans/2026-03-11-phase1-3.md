# Phase 1-3 Portfolio Redesign — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox syntax for tracking.

**Goal:** Transform Jason Steltman's multi-page portfolio into a single-page full-screen snap experience with dark hero, dot nav, and sticky header.

**Architecture:** Rewrite index.html as one HTML file with five full-screen section elements snapped via CSS scroll-snap-type y mandatory. All content is inlined as JS arrays. No build tools, no dependencies.

**Tech Stack:** Vanilla HTML5, CSS3, JS. Google Fonts (Caprasimo, Outfit). Zero npm.

**Note on DOM rendering:** JS render functions build card/modal HTML from statically-authored project arrays. No user input flows into rendered strings — this is not an XSS risk. If user-supplied content is ever added to these arrays in future, switch to DOM text methods or sanitise first.

**Note on testing:** Static site, no test runner. Verification = open index.html in browser and visually confirm. Each task ends with a git commit.

**Spec:** docs/superpowers/specs/2026-03-11-phase1-3-redesign.md

openLightbox(img) / closeLightbox(e):
```
function openLightbox(img) {
  document.getElementById('lightbox-img').src = img.src;
  document.getElementById('lightbox-img').alt = img.alt;
  document.getElementById('lightbox').classList.add('open');
}
function closeLightbox(e) {
  if (e && e.target !== document.getElementById('lightbox') &&
      !e.target.classList.contains('lightbox-close')) return;
  document.getElementById('lightbox').classList.remove('open');
}
```

Escape key handler:
```
document.addEventListener('keydown', function(e) {
  if (e.key === 'Escape') {
    document.querySelectorAll('.modal-overlay.open').forEach(function(m) {
      m.classList.remove('open');
    });
    document.getElementById('lightbox').classList.remove('open');
    document.body.style.overflow = '';
  }
});
```

Dot nav IntersectionObserver (threshold 0.5, root = #snap-container):
```
var sections = document.querySelectorAll('section.snap-section');
var dotItems = document.querySelectorAll('.dot-item');
var dotNav = document.getElementById('dot-nav');
var dotObserver = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (!entry.isIntersecting) return;
    var id = entry.target.id;
    var theme = entry.target.getAttribute('data-theme');
    dotItems.forEach(function(item) {
      item.classList.toggle('active', item.getAttribute('data-target') === id);
    });
    dotNav.classList.toggle('light-section', theme === 'light');
  });
}, { threshold: 0.5, root: document.getElementById('snap-container') });
sections.forEach(function(s) { dotObserver.observe(s); });
```

Sticky header IntersectionObserver (threshold 0, hero section only):
```
var siteHeader = document.getElementById('site-header');
var heroObserver = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    siteHeader.classList.toggle('visible', !entry.isIntersecting);
  });
}, { threshold: 0, root: document.getElementById('snap-container') });
heroObserver.observe(document.getElementById('hero'));
```
